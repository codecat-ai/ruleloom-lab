# Ruleloom Lab

[English](README.md) | [中文](README-zh.md) | [日本語](README-ja.md)

Ruleloom Lab はローカルファーストのブラウザー向け初等セル・オートマトン playground です。Wolfram ルール番号を入力し、シードを選ぶだけで、小さな近傍ルールが驚くような視覚パターンを編み出す様子を観察できます。

## 問題と動機

初等セル・オートマトンは定義は簡単ですが、ルール番号だけでは理解しにくいものです。Ruleloom Lab は、教師、学習者、クリエイティブコーダー、好奇心のある開発者が、三つのセルからなる二値近傍が時間とともに複雑な振る舞いを生み出す様子を、プライベートかつ少ない導入手順で探索できるようにします。

## 機能

- 0 から 255 までのルール番号入力。
- 幅、世代数、シードの制御と、無効値に対する予測可能なクランプ。
- 中央シード、決定的ランダムシード、カスタムビット文字列シード。
- 固定ゼロ境界と循環ラップ境界を比較できる境界モード制御。
- 現在の盤面設定で、アクティブなルールともう一つの Wolfram ルールを並べて比較するサマリー。
- アクセシブルな HTML/CSS セル・オートマトンのグリッド。
- `111` から `000` までの近傍ルール表。
- ステップ、リセット、実行、共有の操作。
- キーボードショートカット。Space で実行/一時停止、ArrowRight または `.` でステップ、`R` でリセット、数字キー `1`-`4` で表示中の順序どおりにプリセットを選択できます。
- ルール、幅、世代数、シード、境界のメタデータを含む、等幅で持ち運びやすいテキストパターンをコピーできます。
- 独立したパターンスナップショット用の SVG コピー操作。
- 現在表示中の世代を決定的な Life/RLE 風テキストとしてコピーできる RLE コピー操作。
- Ruleloom RLE エクスポートを編集可能なカスタムシード設定として復元する、貼り付け RLE インポート操作。
- 現在表示中の世代をローカルのパターンスナップショットとして保存できる PNG ダウンロード操作。
- 現在の設定、比較結果、ルール表、選択中のプリセット/Gallery/Lesson の文脈、生成行、ディスカッションプロンプトをまとめた、決定的でエスケープ済みのコピーしやすい HTML 教師メモを印刷できます。
- Rule 30、Rule 90、Rule 110、Rule 184 のプリセットと、学習者向けの短い説明。
- 製品機能としての Gallery examples セクション。循環ラップ境界とカスタムシードの例を含む、ローカルで適用できる四つの curated setup を提供します。
- シード種別、境界モード、授業での難易度で Gallery examples を絞り込み、該当例がない場合は空状態を表示します。
- 既存のギャラリー例を、名前付きの授業内探究として並べる Lesson paths。所要時間の目安とディスカッション用プロンプトを含みます。
- `src/automata.ts` からエクスポートされる純粋で決定的なエンジン。
- `src/gallery.ts` からエクスポートされる純粋な curated gallery メタデータと適用ヘルパー。
- `src/lessonPaths.ts` からエクスポートされる純粋なレッスンパスメタデータと安全なステップ適用ヘルパー。
- `src/share.ts` のクエリ文字列インポート/エクスポート補助関数。
- `src/textExport.ts` の決定的なプレーンテキストパターンエクスポーター。
- `src/svgExport.ts` の決定的な SVG パターンエクスポーター。
- `src/rleExport.ts` の決定的な RLE 風パターンエクスポーター。
- `src/rleImport.ts` の純粋な Ruleloom RLE インポートパーサー。
- `src/pngExport.ts` の決定的な PNG エクスポート補助関数。単体テスト向けにキャンバスエンコードを注入できます。

## インストール

Ruleloom Lab は GitHub のみで公開されています。npm やその他のパッケージレジストリにはまだ公開していないため、リポジトリから利用してください。

```bash
git clone https://github.com/codecat-ai/ruleloom-lab.git
cd ruleloom-lab
npm ci
```

## クイックスタート

```bash
npm run dev
```

ターミナルに表示されたローカル URL をブラウザーで開きます。

Boundary コントロールを使うと、ルールやシードを変えずに、既定の固定ゼロ境界と循環ラップ境界を比較できます。

Compare with rule を使うと、現在の幅、世代数、シード、境界モードで、二つのルールが最初に分岐する世代と異なるセルの合計を確認できます。

フォーカスがフォームコントロール内にないときは、キーボードショートカットを使えます。Space は実行/一時停止、ArrowRight または `.` はステップ、`R` はリセット、`1`-`4` は表示順に Rule 30、Rule 90、Rule 110、Rule 184 を選択します。

Download PNG を使うと、現在表示中の世代をローカルスナップショットとして保存できます。PNG エクスポートはブラウザー内で完結し、アップロードは行いません。

Paste Ruleloom RLE と Import RLE を使うと、コピー済みの Ruleloom RLE エクスポートをローカルで復元できます。インポートは Ruleloom の `W<number>` ヘッダー、幅、表示世代数、境界メタデータ、カスタムシードメタデータを読み取ります。カスタムシードメタデータがない場合は、最初にデコードした行からカスタムシードを派生します。

Gallery examples を使うと、完成した curated setup を適用できます。シード種別、境界モード、授業での難易度でカードを絞り込み、表示されている例を適用できます。各カードはルール、幅、世代数、シードモード、シード値、境界モード、必要に応じて比較ルールを更新し、表示中の再生状態を最初の行に戻すため、パターンの展開を最初から観察できます。

単独のカードではなく短いガイド付きの流れが必要な場合は、Lesson paths を使えます。各ステップは既存のギャラリー設定を適用し、再生を最初の行に戻し、観察のためのディスカッションプロンプトを示します。

Print teacher notes を使うと、現在の設定からローカルで印刷できる HTML メモを準備できます。メモには、アクティブなルール、シード、境界モード、比較サマリー、ルール表、表示中の生成行、利用可能なプリセット/Gallery/Lesson の文脈、ディスカッションプロンプトが含まれます。

## 例

URL クエリ文字列から決定的な Rule 90 の探索を復元できます。

```text
?rule=90&width=61&steps=80&seed=center&boundary=fixed
```

Rule 30 はカオス的な疑似ランダム成長、Rule 90 は入れ子状のシェルピンスキー三角形、Rule 110 は計算万能な振る舞い、Rule 184 は交通流のような移動を観察するのに便利です。アプリはこれらの説明をプリセット操作の近くに表示します。

Sierpinski lattice はきれいな Rule 90 の中央シードフラクタル、Wrapped traffic loop は循環端を使う Rule 184、Rule 30 noise field は再現可能な決定的な乱雑さ、Custom seed lanes は手作りの Rule 110 開始状態を適用します。

Gallery examples を絞り込むと、入門向けの中央シード活動、中級向けの固定境界ランダムシード活動、上級向けのカスタムシード活動を授業の流れに合わせて見つけられます。

Patterns from one spark を実行すると、約 12 分で Rule 90 の中央シードから Rule 30 の決定的なノイズ、Rule 110 のカスタムレーンへ進めます。Edges change the story を実行すると、約 10 分で固定境界から循環ラップの交通流へ進む境界比較ができます。

共有 URL で `boundary=wrap` に切り替えると、左右の端が互いを近傍として読み取ります。

メインルールを `30`、Compare with rule を `90` にすると、同じ盤面で決定的な分岐サマリーを確認できます。

途中までステップ実行してから Download PNG を使うと、表示中の行だけを `ruleloom-rule-90-w61-g12-center-fixed.png` のような安全なファイル名で保存できます。

Lesson path のステップを適用し、Compare with rule を変更してから Print teacher notes を使うと、その授業時点の正確な表示行とディスカッションプロンプトを記録したファシリテーター用配布メモを作れます。

RLE をコピーしておけば、あとで Import RLE に貼り付けて、保存したルール、幅、表示行数、境界モード、カスタムシードから編集を続けられます。

```text
# Ruleloom Lab
# rule: 90
# width: 15
# generations: 3
# seed mode: center
# boundary mode: fixed
x = 15, y = 3, rule = W90
7bo7b$6bobo6b$5bo3bo5b!
```

## 設定

アプリはブラウザー UI または URL クエリパラメーターで設定できます。

- `rule`: 0 から 255 までの整数。
- `width`: グリッド幅。15 から 121 セルにクランプされます。
- `steps`: 表示する世代数。1 から 160 行にクランプされます。
- `seed`: `center`、`random`、`custom`。
- `boundary`: `fixed` は外側の近傍をゼロとして扱い、`wrap` は循環する端の近傍を使います。無効な値は `fixed` に戻ります。
- `randomSeed`: 決定的な数値ランダムシード。
- `customSeed`: `seed=custom` のときに使うビット文字列。

無効な数値はサポート範囲にクランプされます。境界設定がない場合は、後方互換性のため `fixed` が使われます。

RLE インポートは Ruleloom 自身の決定的なテキストエクスポートだけを受け付けます。`b`、`o`、数値のランレングス、`$` の行区切り、最後の `!` 終端をデコードし、結果を `seed=custom` として適用します。エクスポートメタデータが `wrap` を示さない限り、境界は `fixed` になります。
